# Medizinisches Softwareprojekt SS26

## Thema: KI-basierte Patientensteuerung

## ‼️Wichtig‼️
Zurzeit kann man nicht direkt auf den Main-Branch branchen. Jemand muss vorher den Code reviewen und bestätigen. Das soll verhindern, dass auf eigene Faust etwas im Main gebrancht wird. 

## Organisation des Projektes mit SCRUM
Oben auf der Leiste "Code, Issues, Pull-Requests, Pakete, Projekte, Releases, Wiki, Aktivität" findet man unter der Rubrik "Projekte" ein Projekt namens "MEP". Dort findet man ein SCRUM-Board.
Dieses SCRUM-Board wurde folgendermaßen strukturiert:
 - Product Backlog (alle geplanten Features)
 - Sprint Backlog (aktueller Sprint)
 - In Progress (in Bearbeitung)
 - Review (Code Review / Testing)
 - Done (fertiggestellt)
